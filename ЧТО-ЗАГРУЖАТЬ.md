# Какие файлы загружать на GitHub — простыми словами

## Главное

**Вы НЕ выбираете файлы по одному.**

Вы загружаете **всю папку проекта** целиком:

```
C:\Users\Nikita\Desktop\v2
```

Команда `git add .` сама добавит нужное и **пропустит лишнее** (см. `.gitignore`).

---

## Что попадёт на GitHub (нужное)

```
v2/
├── .github/workflows/deploy.yml   ← автопубликация сайта
├── public/
│   ├── images/
│   │   ├── project-01.jpg       ← ВАШИ 6 фото (обязательно!)
│   │   ├── project-02.jpg
│   │   └── ... project-06.jpg
│   └── css/style.css
├── src/                         ← весь код сайта
├── scripts/build-pages.mjs
├── index.html
├── package.json
├── vite.config.js
├── tailwind.config.js
├── README.md
└── DEPLOY-GITHUB.md
```

---

## Что НЕ нужно загружать (Git сам пропустит)

| Папка/файл | Почему |
|------------|--------|
| `node_modules/` | Тяжёлая, ставится командой `npm install` |
| `dist/` | Собирается автоматически на GitHub |
| `.env` | Секреты (если появятся) |

**Вручную их удалять не надо** — они в `.gitignore`.

## Команды (копируйте по порядку)

Откройте PowerShell:

```powershell
cd C:\Users\Nikita\Desktop\v2

git init
git add .
git status
```

Команда `git status` покажет список файлов, которые **реально уйдут** на GitHub.
Проверьте, что там есть `public/images/project-01.jpg` и т.д.

Потом:

```powershell
git commit -m "Мой сайт портфолио"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin main
```

Замените `ВАШ_ЛОГИН` и `ИМЯ_РЕПО` (например `Nikita` и `vremke-portfolio`).

---

## После push

1. GitHub → ваш репозиторий → **Settings** → **Pages**
2. Source: **GitHub Actions**
3. Через 2–3 минуты сайт: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

---

## Если без команд — через сайт GitHub

1. Создайте пустой репозиторий на github.com
2. **Add file** → **Upload files**
3. Перетащите **всю папку `v2`**, но **без** `node_modules` и **без** `dist`
4. Это неудобно для больших проектов — лучше через `git push` выше

---

## Вопрос «какие именно файлы?» — ответ в одной строке

**Вся папка `v2`, кроме `node_modules` и `dist`, плюс обязательно 6 фото в `public/images/`.**
