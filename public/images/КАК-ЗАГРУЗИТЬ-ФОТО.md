# Как загрузить 6 фото в портфолио

## Шаг 1. Подготовьте изображения

- **Количество:** ровно 6 файлов.
- **Соотношение сторон:** 4:3 (например 1600×1200, 1920×1440).
- **Формат:** JPG, PNG или WebP.
- **Размер:** до 500 КБ на файл (сожмите на [squoosh.app](https://squoosh.app), если тяжёлые).

## Шаг 2. Переименуйте файлы

Скопируйте фото в эту папку (`public/images/`) и назовите так:

```
project-01.jpg
project-02.jpg
project-03.jpg
project-04.jpg
project-05.jpg
project-06.jpg
```

Порядок в галерее = порядок номеров (01 — первый слайд слева).

> Если у вас PNG: назовите `project-01.png` и в файле  
> `src/data/galleryProjects.js` замените `.jpg` на `.png` для нужного проекта.

## Шаг 3. Положите файлы в папку

Полный путь на диске:

```
v2/public/images/project-01.jpg
v2/public/images/project-02.jpg
...
v2/public/images/project-06.jpg
```

В проводнике Windows: откройте папку проекта → `public` → `images` → вставьте 6 файлов.

## Шаг 4. Измените названия проектов (по желанию)

Откройте файл:

`src/data/galleryProjects.js`

Измените поля `title` и `category` для каждого проекта:

```js
{
  id: 1,
  title: 'Логотип для кафе',
  category: 'Брендинг',
  image: '/images/project-01.jpg',
},
```

## Шаг 5. Обновите сайт в браузере

Если запущен `npm run dev` — сохраните файлы и обновите страницу (**Ctrl + F5**).

Если фото не появилось:

1. Проверьте имя файла (без опечаток, с нулём: `01`, не `1`).
2. Проверьте, что файл именно в `public/images/`, а не в `src/`.
3. Откройте в браузере: `http://localhost:5173/images/project-01.jpg` — должна открыться картинка.

## Быстрая проверка

| Файл на диске              | Должен открываться по адресу                    |
|----------------------------|-------------------------------------------------|
| `public/images/project-01.jpg` | `http://localhost:5173/images/project-01.jpg` |

---

**Не нужно** менять `Gallery.jsx` — только файлы в `public/images/` и при желании `galleryProjects.js`.
