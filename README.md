# Vremke — Portfolio

Одностраничное портфолио: React, Tailwind CSS, Framer Motion.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация на GitHub Pages

**Полная инструкция:** [DEPLOY-GITHUB.md](./DEPLOY-GITHUB.md)

Кратко:

1. Создайте репозиторий на GitHub
2. `git init` → `git add .` → `git commit` → `git push`
3. **Settings → Pages → Source: GitHub Actions**
4. Сайт: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

Сборка вручную:

```bash
npm run build:pages -- имя-вашего-репозитория
```
